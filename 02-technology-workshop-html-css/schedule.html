Schedule for Technology Workshop 2026

Our full-day program is packed with hands-on sessions, exhibitions, and expert talks designed to give you a well-rounded tech experience. From coding fundamentals to robotics, project showcases, and career insights — here's how the day unfolds.

Time Session
09:00 AM – 09:30 AM Registration and Welcome
09:30 AM – 09:45 AM Principal's Speech & Introduction to the Event
10:00 AM – 12:00 PM
    Coding & Programming Session
    1. 1st Hour — HTML & CSS Basics
    • Learn the structure of a web page using HTML tags and elements.
    • Style the page with CSS — colors, fonts, layout, and spacing.
    • Build a simple personal web page from scratch.
    2. 2nd Hour — Python Fundamentals
    • Introduction to Python syntax and data types.
    • Control flow statements (if/else, loops).
    • Functions and modules.
12:00 PM – 12:30 PM Short Break (Treats from IT Society & Old Boys' Association)
12:45 PM – 02:00 PM Student Project Exhibition
02:00 PM – 02:45 PM Lunch Break
02:45 PM – 04:00 PM Robotics & Electronics Session
04:00 PM – 05:30 PM Technology Career Discussion
05:30 PM – 06:00 PM Closing Ceremony
