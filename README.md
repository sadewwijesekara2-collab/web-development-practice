# Web Development Practice

A collection of my HTML, CSS and JavaScript learning exercises and small web projects. The folders are arranged in a learning order.

## Projects and exercises

| Folder | Description |
|---|---|
| `01-html-basics-session-1` | Introductory HTML pages and basic page structure |
| `02-technology-workshop-html-css` | Multi-page Technology Workshop website using HTML and CSS |
| `03-campus-quest` | Campus Quest page; includes full and alternate versions |
| `04-event-registration` | Event registration website; includes full and earlier versions |
| `05-javascript-day-6` | JavaScript practice with HTML and CSS |
| `06-javascript-day-7` | JavaScript practice project |
| `07-javascript-day-8` | JavaScript practice project |
| `08-portfolio` | Personal portfolio website and retained alternate versions |
| `09-technova-website` | TechNova event website with registration page |

## How to run

1. Download or clone this repository.
2. Open the relevant project folder.
3. Open its `index.html` file in a web browser.
4. For projects with multiple pages, use the navigation links in the website.

Some folders contain more than one version of an exercise. They are kept separately so earlier work is not lost. The repeated Day 1 folder from the original upload was identical, so only one copy is included.
